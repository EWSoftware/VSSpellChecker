Changes made in this release:

- Dependency assemblies are now embedded in the code analyzer assembly.  This should fix an issue occurring for
  some users where the code analyzer was failing to find them when the assembly is loaded from a cache folder
  rather than the installation folder.
- Default dictionaries are also now embedded in the common spell checker assembly and extracted to the
  application data folder on first use.  This was also done to allow the code analyzer to find them when not
  running from the installation folder.
